# Windows Store 优化指南

## 当前问题

- ❌ 安装量：13（一个半月）
- ❌ 平均每天：< 1 次安装
- ❌ 转化率：极低

## 根本原因

### 1. 可发现性问题
- Store 搜索排名低
- 关键词不匹配
- 分类不准确

### 2. 产品页面问题
- 截图不够吸引人
- 描述不够清晰
- 缺少视频演示

### 3. 推广不足
- 没有外部流量
- 没有社交媒体推广
- 没有用户评论

## 竞品分析

### 主要竞品
1. **Notion**（免费 + 付费）
   - 优势：功能强大、云同步
   - 劣势：需要网络、隐私问题

2. **Obsidian**（免费 + 付费插件）
   - 优势：本地存储、插件生态
   - 劣势：学习曲线陡峭

3. **Typora**（付费 $14.99）
   - 优势：简洁、Markdown
   - 劣势：付费、功能单一

### Grain 的差异化

**核心优势：**
1. ✅ 完全免费开源
2. ✅ 本地存储，保护隐私
3. ✅ 简单易用，无学习曲线
4. ✅ 专为长文写作优化
5. ✅ 跨平台（Windows/Linux/Mac）

**宣传口号：**
```
"像 Notion 一样强大，像 Typora 一样简洁，
但完全免费，数据完全属于你。"
```
